# Violet Orbit · Light

本轮前端美术由 DeepSeek Harness（V4.1-Flash 1017）设计实现。

- 赛事主题为浅色紫色：瓷白面板、淡紫轨道背景、深紫文字。
- 左队为红队，右队为蓝队；队伍色用于标记、星位、玩家窗细边和领先比分。
- Mappool、Playing、单图结算共用同一背景。
- 背景光层缓慢漂移，状态轻量过渡；游戏窗口固定，支持减少动态偏好。

配色、字体及图层说明见[项目设计文档](../../DESIGN.md)，截图和检查见[视觉验收记录](visual-verification.md)。先收束 UI，再整体迁移 Vue 3 + Vite + TypeScript。
