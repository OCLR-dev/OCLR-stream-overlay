# OCLR S11 规则映射（UI 评审用）

> 来源：[OCLR S11 tournament rules](https://oclr.org/tournaments/s11#rules) · 版本 **1.6** · 核对日期 **2026-10-26（America/New_York）**。
>
> 本文是直播 UI 的规则映射，不是官方规则原文、赛果或数据源。S11 报名结束前人数、图池和细节仍可能变化；当前页面的所有队伍、选手、谱面、比分和状态都是本地示例。

## 1. 已确认的赛制信息

- 赛制为 Draft、Score v2。
- 常规人数尚未最终确定为 3v3 或 4v4。参赛队名单为 5–6 人时上场 3 人，7–8 人时上场 4 人。
- 小组赛 / 淘汰赛 BO11，先到 6；决赛 BO13，先到 7。
- 双方各 2 个 Ban，不设总决赛 reset；正式图池规模待定。
- roll 胜者选择先/后 Pick，另一方选择先/后 Ban，两项权利独立。实际先手未知，不由 UI 推断。
- Ban 60 秒、Pick 90 秒、准备 120 秒。Ban 超时为空 Ban；Pick 超时由裁判 roll 处理。不自动判罚。
- 默认 NF。FM 每队至少一名单 HD（含 EZ/HDEZ）和一名单 HR，共 2 人；CS≤4 时 EZ 为 1.5 倍。
- TB 允许 HD/HR/HDHR/EZ/EZHD，EZ 无加成。不实现最终计分算法，不对上游分数二次乘倍率。
- 常规人数与图池规模均待定；不以占位布局声称正式数量。

## 2. EX：规则记录与当前 UI 范围

### 2.1 规则记录

- EX 每队每场最多 2 次；TB 禁 EX。
- 仅在自己 Pick 时立即声明；双方各自第一次 Pick 均禁 EX。人数不足、少 Pick、获胜或本场禁 EX 的处理由裁判确认，不能自动加星或自动判胜负。
- **本轮 UI 不实现 EX 人数/阵容/窗口联动，也不实现首 Pick/对方 Pick 判断引擎。** EX 只作为人工确认后的展示标记：当前图开启方为未开启 / 示例A队 / 示例B队。
- Mappool 显示双方人工设置的 EX 剩余次数（0/1/2）。选标记、切场景、单图结算和全场胜利都不自动扣减次数、改变阵容/窗口数、加星或写结果。
- EX 开启时 Captain/T1 不上场的限制保留记录；EX 窗口数/阵容联动**待最终赛事规模确定后实现**。本轮只做展示标记，不预设后续算法；当前窗口数仍由独立的常规 3v3/4v4 评审选择决定。

### 2.2 当前 UI 的具体处理

| 信息 | 当前处理 |
| --- | --- |
| EX 开启队伍 | 当前图显示 `EX · 示例A队开启` / `EX · 示例B队开启`；未开启时明确显示 `EX 未开启`；TB 显示 `TB · 禁 EX`。 |
| EX 剩余次数 | Mappool 状态条显示 A/B 各 0/1/2，仅由画布外人工设置。 |
| EX 与窗口 | 不改 POV 数、阵容角色或结算分数；常规 3v3/4v4 独立切换。 |
| EX 与 TB | TB 禁 EX：切到 TB 时清除当前 EX 标记并禁用 EX 开启方控件，EX 剩余次数保留，不自动消耗。 |
| EX 与星位 | 不自动加星，也不自动进入全场胜利。 |

## 3. Ban / Pick UI 边界

- Mappool 保留三列谱面占位和聊天，并新增双方各 2 个 Ban 槽。
- Ban 槽区分 `未确认` 与 `空Ban`；同队两次 Ban 不得同 mod（NM/FM 例外）。TB 不可 Ban。
- 本地演示只做槽位状态与校验反馈，不是完整 BP 引擎，也不推断行动顺序、地图分配或正式池规模。
- 先 Pick 与先 Ban 分开人工选择，默认未确认。
- 谱面列表是占位，带 NM/HD/HR/FM/TB 模组标签；18 行只是布局骨架，不代表正式图池数量。
- 首 Pick / 对方 Pick 的 EX 资格已记录在本文，但本轮不构建校验引擎。

## 4. 直播人员/暂停映射

- 战术暂停每队每场最多 1 次，暂定 3 分钟；技术处理不自动消耗战术暂停。
- 30 秒后掉线每队有 1 次重赛机会，须裁判确认。
- 不自动 FF、不自动重赛、不自动判定胜负、不自动倒计时。恢复时间未确认时只显示未确认。

## 5. 画布与结果的硬边界

- 固定 1920×1080、六个场景、灰白低保真、源比例 contain。
- Playing 与单图结算保持逐窗同位同尺寸；单图结算内保留 osu! 原生结算占位，不制作逐人成绩表。
- 结算总分只按当前常规上场人数求和，独立于 Playing 的领先演示按钮；EX 标记不改变结算人数或分数。
- Playing 的固定中线分差带仍是 CSS 300px、五态 scaleX `-0.266667 / -1 / 0 / +0.266667 / +1`；不改为滑块，不发明正式映射。
- 到场不等于 ready；缺失值不是 0；未接入真实数据时不伪造正式结果。
- 全场胜利是独立占位场景，显示阶段和 BO 目标，但不造正式冠军。系列星位为人工演示，默认未知空星。

## 6. 待定与风险

1. 常规人数最终是 3v3 还是 4v4。
2. 正式图池规模、分组和具体谱面。
3. EX 窗口数/阵容联动在最终赛事规模确定后实现；不得提前写死。
4. 报名结束前规则版本可能继续更新；应以当时官方页面和赛事方确认版本为准。
5. 真实赛果、选手名单、图池、聊天、OBS 和 tosu 均尚未接入。本页不是正式结果或裁判工具。
