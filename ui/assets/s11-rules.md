# OCLR S11 直播 UI 规则映射

根路径的评审页用示例队伍检查画面。正式比赛在 `/control` 操作，`/overlay` 读取本机会话。以下说明帮助评审者核对显示和操作；本场适用的赛制、阵容、暂停与判罚以赛事方确认的规则为准。[OCLR S11 赛事规则](https://oclr.org/tournaments/s11#rules)

原评审稿保留了 2026-10-26 核对的 v1.6 规则条目，包括限时、EX 声明时机和裁判处理。可按日期查阅[当时的规则映射](https://github.com/OCLR-dev/OCLR-stream-overlay/blob/518e02c9928c22f726a6ba8843f9ebe3ba7bbc55/ui/assets/s11-rules.md)。

## 正赛

| 环节 | 在直播 UI 中如何体现 |
| --- | --- |
| 人数与目标 | 使用本场人数和阶段。S11 正赛的常规布局支持 3v3 和 4v4；阶段预设为小组／淘汰 BO11、决赛 BO13。 |
| Roll 与 BP | 先 Ban 与先 Pick 分别指定。每队有两个 Ban 槽，空 Ban 与未确认分别显示，TB 单独准备。图池显示已确认的动作。 |
| EX | 普通图准备期间可设置开启方。双方各减一路，3v3 变 2v2，4v4 变 3v3。正赛按两队各自的剩余次数显示，本次 Pick 有有效胜负后扣一次。改胜方保留这次消耗，明确重赛撤回旧尝试的贡献。 |
| TB | 双方系列赢图都达到先胜目标减一，核对赛果后准备本场唯一 TB。TB 使用常规人数，禁 Ban、禁 EX。 |
| FM 计分 | FM 中实际使用 EZ 的选手，其客户端分数额外乘 1.5，逐人四舍五入后汇总。实时队分、分差与结算使用同一口径。 |
| 暂停与重赛 | 导播选择暂停类型，可设置倒计时。「即将开始」单独触发返场。裁判确认重赛后，控制台为同一张图建立新的尝试。 |

表演赛读取任务给出的先胜目标或固定图数，按本场规则记录胜负或平局。表演赛使用独立的 BP 和 TB 处理，正赛 EX 只在正赛中出现。

## 在演示页核对画面

- 用评审控件切换人数、源比例和 EX，检查选手窗口是否对齐。Playing 和 Ranking 使用同一组窗口。
- 顶栏系列分和赢图菱形对应本场进度。Playing 收到双方有效的本图队分后显示实时总分。分差条按绝对分差线性伸展，25 万分填满半条。
- 评审页的队名、选手、谱面和分数用于预览。正式控制台可从已指派的任务导入队伍、图池与赛制，并从 tosu 跟随现场。
