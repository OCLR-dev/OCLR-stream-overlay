# MP5 Xronicle — Windows x64 测试包 R3（2026-10-30）

适用于 Windows 10 / 11 的 Intel / AMD 64 位电脑。无需安装 Node.js、Git、Python；运行环境已包含。程序未签名；不需要关闭系统安全防护。Windows 原生启动与真实 osu!tourney／tosu 联调尚未在实机验收，请先测试。

1. 把 MP5-Xronicle-Windows-x64-20261030-r3.zip 整个传到 Windows（U盘、局域网或你常用的文件传输工具均可），右键“全部解压”。不要在压缩包里运行，也不要只复制 exe。
2. 先退出旧包的服务窗口，把R2完整解压到新的文件夹，用同一Windows账户启动 **MP5-Xronicle-Test.exe**。当前用户实机反馈需要右键“以管理员身份运行”；普通权限启动问题尚未完成修复。保留启动小窗口，可最小化；网页关闭不影响服务。重复双击复用同一服务。
3. 浏览器打开 http://127.0.0.1:3011/control 。只读输出为 http://127.0.0.1:3011/overlay ，画幅 1920×1080。
4. 首次启动已装入本次提供的真实资料：MP5 Xronicle、瑞士轮、BO9 先赢5；左红队“好麻烦啊......”，右蓝队“我发现队友都玩osu”；17张图，NM5 / HD2 / HR2 / DT3 / FM2 / CA2 / TB1。队名及省略号按截图录入，可在开播前设置修正。常规窗口人数暂沿用原4v4默认占位，实际人数尚未提供，请开播前核对。阶段未擅自解释为第二轮，图池来源为“瑞士轮图池（二）”。比分从0:0开始。
5. 图池使用一组自由选择的“队名 Ban / Pick”按钮：可先点动作再点谱面，也可先选谱面再点动作，不用填写整场队列。允许直接从当前 Pick 加入，之前未跟踪的 Ban／Pick 保持未知，不要求补齐。本场单轮 Ban 后交替 Pick 在“开播前设置 → BP 流程”选择；两项先手独立，胜方不改轮换。已打图或进行中的图仍可修改播出标记，不改写原局、赛果或系列比分。CA 保留独立分类，不推断模组要求。
6. 这台电脑已有 osu!tourney；自动跟随还需运行 **tosu**，让它读取实际比赛房间。在“房间连接与自动跟随”填写 tosu 显示的实际 WebSocket 地址，核实 stable / osu!tourney，再分别填写实际房间左右队名。**不能把播出队名直接当作房间绑定**。当前地址／绑定留空，自动化意图保留但不执行。不包含 tosu、osu!tourney 或游戏视频捕获。
7. 名单、队旗和图片可后补。谱面封面和参数仍按原链路获取；初次封面读取可能需要等待网络。当前游戏窗口是“等待游戏捕获接入”占位，不会自动获得选手视频。
8. 结束时在启动窗口点“退出直播服务”；不要删除数据来排障。下一次启动恢复本地修改。当前未操作或配置 OBS。

## 数据和搬迁

独立数据目录：`%LOCALAPPDATA%\OCLR\CustomMatchTest`。不会读取或覆盖原 OCLR 的 `StreamOverlay` 数据，也不加载 OCLR 凭证或线上赛事。退出程序后可备份整个 CustomMatchTest 文件夹。

若原有会话的图池为空，可把随包“图池录入.txt”的17行复制到“开播前设置 → 本场图池”，修改后自动同步，不用初始化或清空比分。

程序目录中的 app\match-template.json 是首次启动配置。**已有比赛时以用户数据目录为准，更新程序不会覆盖比赛**；不要用模板覆盖进行中 session.json。需要另一场时在控制台初始化（先存档、可撤销），然后录入新资料。比赛配置.json 是随包保留的原始配置副本，不是正在使用的比赛记录。

将程序解压到其他目录后仍用同一用户数据。另一台 Windows 需要搬运行中比赛时，先退出两台程序，再备份并复制整个 CustomMatchTest 目录；目标已存在比赛时先核对，不覆盖。实际 tosu 地址和房间绑定应在目标电脑重新核实。
