# Windows 桌面直播控制台

v0.3.1 · [Issue #66](https://github.com/OCLR-dev/OCLR-stream-overlay/issues/66)

双击 `OCLR.exe` 后，直接使用「直播控制台」的比赛配置和比赛现场。顶部另有 Showcase、服务、设置、日志和关于。「在浏览器打开」可使用同一份比赛；OBS 地址见「设置 → 复制全部地址」。切换页面、重新加载控制台或最小化时，Node 继续运行。关窗或点「退出服务」后，在确认框同意才停止输出并保存比赛。

端口占用或启动失败时，控制台可重试、改端口或查看日志。短暂失联时保留页面并等待原 SSE 重连。重启会重新载入新服务与端口，继续使用同一比赛目录。OCLR 连接凭证在服务重启后需重新授权，OBS 地址沿用已有同步流程。

## 授权和页面边界

桌面与网页运行同一套 Vue 组件。控制台和 Showcase 各自在 Node 的本机来源加载。Node 只允许启动器来源嵌入这两个入口，API 仍按原有同源规则验证。Wails 外壳只接收来自当前 frame 和端口的导航及固定链接请求，文件选择、端口设置和启动程序保持在 Go。见 [WebView2 安全指南](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security)。

在桌面点「登录 OCLR」后，由系统浏览器打开本机授权页，点「前往 OCLR 授权」沿用网站弹窗握手。授权凭证仍通过既有流程交给 Node，在内存中保存。桌面通过共用 SSE 收到授权状态，应用窗口不接收网站凭证。浏览器原有控制台与手动授权入口继续可用。

Windows x64 需要 Microsoft Edge WebView2 Runtime。缺少运行时时按提示安装，再重新打开。无网络的电脑请预先安装运行时。见 [Windows 使用说明](../../windows-portable.md)。

## 验证记录

- **Windows 11 实际窗口，合成赛事。** 默认进入内嵌控制台，切换比赛配置，Overlay 预览随会话同步。暂停通过原 API 写入同一场比赛，重新加载控制台、从嵌入链接打开 Showcase 并返回后仍保持暂停，随后正常撤销。点击桌面登录唤起系统浏览器。
- **自动化，合成赛事。** 校验启动器 iframe 的来源、页面及方法白名单，浏览器控制台与授权入口，以及桌面、网页和输出共用的 Node 会话。原便携验证覆盖退出保存、旧记录恢复、端口冲突、健康监测与恢复。网站握手状态、授权撤回和凭证投影使用合成服务测试。
- **实机待验收。** 桌面操作被中止后未继续验证缩窗、实际中文输入法、图形改端口与外部授权提交。缺少 WebView2 的全新系统及真实 OCLR／tosu／OBS 直播联调未执行。
