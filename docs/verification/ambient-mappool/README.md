# 背景与 Mappool 验收

日期：2026-10-31。基于 `6900b45`，确认后的视觉改动同步到 main 与 test/custom-match，保留各自功能差异。

## 最终表现

- 全画布36个淡紫/灰白菱形，描边与实心混合，单次漂移6–10秒，常态速度为最初方案两倍；所有场景数量相同。
- 红蓝顶部自由扩散光点各26个，2.4–4.5px，略微提亮并增强光晕，仍限制在顶部180px内。
- 去除旧背景呼吸光，未采用雾光、圆环、轨道或导引线。装饰仅使用独立元素的CSS transform/opacity，固定路径不读取比赛状态，无JS动画定时器或新增依赖。
- Mappool删除中间“当前模式/MOD”“EX未开启”提示。先手标签只显示先Pick/先Ban，按实际归属着红/蓝色，距队名20px；红队在队名右侧、蓝队在队名左侧。同队可同时显示两项，未知时不猜测。
- 下行左侧为Ban 1→Ban 2→EX剩余，右侧为EX剩余→Ban 1→Ban 2；活动EX标记留在所属队伍。长队名省略并保留完整title。
- 游戏捕获与祖先没有新增位移、缩放、透明度或滤镜；系统减少动态效果时停止背景和顶部动效。
