# Showcase 换图过场预览（Issue #57，本地预览）

本分支只做美术与时序预览：`/showcase?cover-demo=1` 是独立评审页，谱面、封面、osu! 画面以及 tosu／OBS 信号全部为本页模拟，不读写共享会话，不连接 tosu 或 OBS。尚未接入服务端状态、OBS WebSocket 或正式 `/showcase`。

## 已确认的方向（2026-11-16）

- 遮挡与揭开全部由服务端经 OBS WebSocket 切换场景完成，控制台不加按钮；没有 ws 时，直播员在 OBS 手动点过场场景作兜底。
- 过场用独立场景覆盖整个 1920×1080 画面，不只遮回放区。
- 不处理声音：成绩页欢呼与选歌试听照常播出。
- 保持画面加入图池进度条。

## 画面

「斜幕换图」：8 条与 Winner／Showcase 背景同角度（115°，即偏离竖直 25°）的深紫斜幕从右侧依次滑入，盖满全屏；揭开时继续向左滑出，一个方向走到底。

- **锚点**：顶部 STAGE 标题、底栏分隔线和左下 S11 Logo 使用 Showcase 相同的类名与坐标，与下层画面像素一致，斜幕从它们下方穿过，切换前后无接缝。
- **保持态完全不透明**：斜幕下有不透明底板，装饰只叠在不透明层之上，不做毛玻璃。
- **状态 A · 品牌待机**：`MAPPOOL / SHOWCASE` 字标。谱面未变（同图重播）或不在图池时使用，避免把刚播完的谱面标成下一张。
- **状态 B · 下一张**：客户端已换到另一张且能匹配 Slot 时显示。880×495 封面（无封面时用 Slot 色块大字）、`NEXT MAP`、Slot 色块、标题、艺术家、难度。标题按长度（中日文计 2）超过 40 时改为 46px 三行，避免截断。图池数据没有谱师字段，不显示谱师；参数仍由 Showcase 底部谱面卡负责，过场不重复。
- **图池进度条**：占用原谱面卡与弹幕所在的底栏 (480–1890, 934)，按 mod 分组；已演示＝mod 色半填充，下一张＝实色上浮并发光，未演示＝描边加顶部色条。方块宽度按张数自适应（13／18／24 张分别约 96／67／48px），右侧显示 `已演示 / 总数`。
- 不使用红蓝（无队伍语义）与鎏金（系列比分专用）。

## 时序（初值，待实机调整）

| 阶段 | 触发 | 动作 |
|---|---|---|
| 进入 | 本次回放结束后进入同图成绩页，展示 3.5 秒 | 8 条斜幕依次滑入：每条 520ms，间隔 22ms，缓出，约 674ms 盖满；500ms 起内容 300ms 上移 6px 淡入 |
| 硬切 | 3.5 秒内已离开成绩页／换图，或揭开过程中再次需要遮挡 | 当帧完全盖住，内容 160ms 淡入，不播斜幕 |
| 保持 | 不限时长 | 斜纹 13.24s 漂移和上浮菱形；客户端换图时 A→B 交叉淡化 200ms，Slot 与进度方块各强调一次 240ms |
| 揭开 | 回放播放状态稳定约 300ms | 内容 150ms 淡出；60ms 起斜幕依次向左滑出（每条 460ms，缓入），约 674ms 完成后切回 Showcase 场景 |

减少动态效果时，进入与揭开都改为 200ms 整体淡化，硬切仍为当帧。首次加载时若已处于遮挡状态，直接显示保持态，不补播进入动画。

## OBS 方案（尚未实现）

- 新建 `OCLR · Showcase 过场` 场景：嵌套 `OCLR · Showcase` 场景，再在最上层放一个全屏透明浏览器源（建议 `/showcase?clean=1&layer=cover`）。嵌套后，斜幕滑入和滑出时盖住的是直播员已摆好的实时回放，不依赖采集源名称或位置。
- 服务端：成绩页 3.5 秒后把 Program 切到过场场景（两场景切换瞬间画面相同，常规淡化不可见）；确认回放开始后先播揭开，结束后再切回 Showcase。Program 不在这两个场景之一时不切换，人工切到休息／广告后不抢回。
- 手动兜底：直播员点过场场景时，页面通过 OBS 浏览器源的激活事件播放进入动画；揭开仍跟随 tosu 自动完成，之后停留在过场场景也与 Showcase 画面一致。
- 断线、打开失败或取消播放时保持遮挡，不自动揭开。

## 边界

- 全部为合成浏览器画面，不代表真实 Windows osu!／tosu／OBS 合成验收。
- 250ms 检测延迟和 300ms 播放稳定时间都是假设值，需实测 tosu 对普通客户端 `ResultsScreen` 与回放播放的识别时机。
- 若直播员在成绩页直接拖入 `.osr`，下一份成绩页可能在检测延迟内露出；正常流程应等过场盖住后再打开 rep。
- 演示封面为本地生成的抽象图；正式实现应沿用 Showcase 底部谱面卡的标题、封面来源。
