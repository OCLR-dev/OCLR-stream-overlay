# Mappool 先选动作验收

2026-10-30（America/New_York）。仅发布通用“先选动作”交互，不带入自定义赛事、MP5资料或单轮Ban规则。

Mappool 在谱面列表前提供双方各自的“下一步：队伍 Ban / Pick”。未选谱面也可点击，立即通过共享会话设置真正的待执行动作。随后匹配房间中的新换图经过现有稳定防抖，再执行该动作；选择动作本身不标记任何谱面、不新增比赛记录、不计胜、不切换全局人工状态。

Ban 自动选择该队尚未完成的槽位。Roll 原有独立先手与完整OCLR顺序继续保留；点击只是明确修正本次待执行动作。如同一动作已在后续队列中，会移到当前且只执行一次，其余后续动作保持相对顺序，不重复消费。没有既定后续时只执行明确选择的一步，不猜整场规则。人工补做仍为选择谱面后完成当前真实动作，普通播出标记区继续独立。

准备中或进行中的图不能用下一动作跳过；改图继续使用“替换本次准备图”。暂停、本图异常、系列结束和TB边界均保留。命令产生新动作身份，原来正在防抖的旧换图不会转给新动作。修改可撤销、刷新恢复。
