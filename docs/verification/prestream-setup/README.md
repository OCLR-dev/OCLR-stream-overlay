# 开播前设置改版验证

2026-11-15，基于 `codex/osu-tourney-launcher`。控制台实现位于 Vue 前端。

## 实现

- 本场比赛、游戏连接、OBS 与播出画面、其他设置与比赛记录分组。桌面右栏显示本场摘要、当前观众画面预览与待处理事项，1000px 以下单栏，预览可收起。
- 游戏实际数据状态和自动跟随选项分开；过期或控制台断线时通过既有 `liveRoom` 校验隐藏房间队名。OBS 状态读取失败时显示待更新。
- OCLR 已连接时收起授权赛季、断开与备用授权，保留任务选择、对阵预览、格式化本地时间、图池与赛制。已载入的相同任务显示「本场正在使用」，其他任务沿用明确载入操作与服务端守卫。
- OBS 当前播出与场景集合集中显示，场景／捕获窗口按需展开，游戏源比例即时修改。
- 弹幕组件供控制台与 Showcase 共用。身份码默认掩码，粘贴自动配置，手动输入失焦或回车提交，IME 组字回车不提交。失败保留输入供重试，成功清空；场景集合变化清理输入并隔离旧请求反馈。
- 配置完成只显示结果、更换身份码入口和实际画面核对提示。等待 OBS、等待场景、配置中、失败有独立反馈。页面显示的是弹幕源配置结果。
- 补齐准备状态、游戏、OBS、弹幕、连接、重试等 Lucide 图示。`@lucide/vue` 1.73.0 固定版本，Vue 3 兼容，安装审核为 0 个漏洞，ISC 与 Feather MIT 声明保留于根目录第三方声明。

## 验证

- Vue 类型检查与 Vite 生产构建通过。
- 完整 Node 回归 541 项通过。后续 UI 收束后再运行 OBS、Showcase、弹幕 CSS、直播任务和页面服务相关测试，52 项通过。
- 初次受限环境的回环连线测试失败，改在可使用本机回环连接的环境后通过。
- 3001 实际服务显示已连接的 OCLR 任务、当前场次、OBS 当前场景与已配置弹幕状态。核对任务折叠区、图示、OBS 紧凑版面与控制台／设置页切换。
- 默认桌面、900×640、390×844 浏览器检查，窄屏文档宽度均未超出视口，表单、下拉与进入比赛现场入口可用。
- 独立 3012 内存服务为 **synthetic**，使用构建后的实际控制台，拦截测试端 OBS 响应且无上游访问。验证无效身份码报错、首个配置请求失败、重试成功、成功清空并恢复掩码、等待场景与 OBS 断线提示。
- 浏览器未执行真实比赛变更、替换真实身份码或重建实际 OBS 场景。实际 B 站消息送达、OBS 音画合成及真实游戏联调仍需实机验收。
