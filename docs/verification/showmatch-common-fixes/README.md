## 改动

- 元数据读取复用并发与成功缓存，失败结果不再永久缓存。图池及谱面底栏失败后间隔 65 秒重试，组件卸载/换图清理等待任务，移除的图池条目不再请求。

- 显式手动 BP 队列在没有当前动作、没有准备/进行中局次、暂停、异常或结束条件时，从首项开始执行。已有当前动作保留，准备/进行中局次结束后才推进。缺少自定义 BO 时继续等待，不自动套用 OCLR 顺序。

自定义版的 BO、文本 BP 规则、单 Ban 交替 Pick 预设、CA、独立运行和七秒 Pick 展示保持。主版新增的表演赛资料导入与 Roll 默认交替 Pick 不适用于此分支，没有合入。
