# 顶栏通栏与队名跟随队旗验收

2026-11-03：按用户要求调整六场景共用的顶部头图。

## 结果

- 左右队色块由原来的画布内 260px 留白改为向外通栏：左队覆盖画布 x=0–880，右队覆盖 x=1040–1920，中央 160px 的 OCLR 盾牌与阶段条区域保持不变，内缘斜切、队色渐变和底部白线延续原样。
- 120×72 队旗随外缘移动，距画布左右两侧各 32px；左旗位于 x=32–152，右旗位于 x=1768–1888。
- 队伍名称从比分列拆出，定位到队旗内侧上角：左队名称从 x=180 起向右排列，右队名称以 x=1740 为右端向左排列，与旗面保持 28px 间距；文字上沿与旗面上沿对齐（`top: 23px`，截图实测均落在 y=30），长队名仍单行省略，上限 360px。
- 系列比分、赢图菱形、Logo、阶段条、场景内容、捕获几何和业务逻辑均未修改；控制台内嵌预览和独立 `/overlay` 共用 `ui/broadcast.css`。
