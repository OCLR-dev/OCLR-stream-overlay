## 使用方式

点选谱面，再点对应队伍的 Ban、Pick 或“清除标记”，立即同步。已有标记和已打过的谱面都能直接改，不需要先清除，不切换修正模式，不再要求确认。操作栏随左侧面板滚动保持可见。

红队 Ban / Pick 显示红框，蓝队 Ban / Pick 显示蓝框，内部统一为中性灰。控制台卡片和独立输出保持一致；保留动作文字区分 Ban / Pick，未标记卡片不显示“未选”。卡片边框使用原有占位与内描边，不因标记改变尺寸。没有可靠队属的演示状态保持中性，不猜红蓝归属。

图池里的 Pick 只改播出标记。实际本局在 Playing 中选择谱面、选图队伍并准备，开打和记胜仍在那里管理；准备下一局保留上一局待记赛果。原自动 BP、Playing / Ranking、异常、重赛、系列分纠错逻辑继续保留。

人工标记保存到本机共享会话 `poolMarks`，优先于自动显示；清除是明确的无标记，旧轮次不会把它重新填回。新命令 `map-mark` 不更改逐局记录、系列分、当前局、BP 动作/队列、实际 Ban 槽、自动跟随锁定或异常；同时保留自动观察连续性。刷新、持久化和撤销都支持，旧会话缺少该字段时也能正常撤销。本场结束后准备下一场会清空本场标记。

原“Ban 修正”在维护区域改称“自动跟随的 Ban 记录”，只处理自动跟随记录。普通直播员改播出标记直接使用图池，不需要接触它。

## 运行与边界

新版包含服务端命令，已运行的旧 Node 进程需要重启后才能接收新命令；单独刷新旧服务页面不足以加载新后端。为保留原有服务和会话，本轮没有重启它们。可直接查看新版隔离预览：`http://127.0.0.1:3010/control` 与 `/overlay`。

所有操作只写本机直播会话，不向 osu! mp 房间发送命令，不修改 mp 赛果或 OCLR 网站赛事数据。当前仍是本机浏览器和模拟 WebSocket 验证，未完成真实 tosu / osu!tourney / OBS 联调，既有结算时序限制仍保留。本轮没有修改系统设置。
