- BP 与恢复：清空 Ranking 客户端后能继续识别下一图；明确换图不自动覆盖已准备的本图；保留后续队列的动作提前；撤回 BP、直接修正 Ban 槽、中止本图、重赛与局部恢复；清除本场记录可撤销。
- 常用操作：暂停倒计时、即将开始后自动返回、Winner 倒计时、热身显示、EX 结算一次扣次与裁判重赛返还；保留独立人工次数修正。
- 播出：完整聊天填充、时分秒、BanchoBot 黄色、仅当前直播槽位用户跟随队色；四位分组队分、自动计胜提示、谱面图片异常恢复、封面全尺寸及星数重试、滚动文本、图池卡片与通栏顶栏。
- 开发与 Windows：自动构建监视器、公开脱敏 tosu 回放工具、启动器 UI / tosu 检测与路径记忆、图标及许可、发布分支与顺序版本工作流。发布仍仅由 release/windows 触发，本次没有发布 Windows ZIP。

## 自定义赛保留与适配

- 标题、阶段名、1–31 的明确奇数 BO、独立先 Ban / 先 Pick、文字 BP 及单轮 Ban 预设、CA 分类。未明确规则时等待，未给定 BO 时不推断目标。
- 不导入 OCLR 表演赛 / 直播任务，不加载配置凭证；禁用对应 HTTP 入口并隐藏导入 UI。自定义入口仍为 3011，使用独立会话。
- 自定义文字 BP 没有主线四阶段按钮；仅单轮 Ban 预设提供它实际包含的 Ban / Pick 阶段。
- Pick 继续七秒；首次收到相应房间换图时重新计时，保存失败重试。
- CA 参数继续显示实际客户端范围，官方测试仅使用明确的 NM 基线。FM 的 EZ 加分规则保持，NF 没有额外倍率，CA 不套用 FM EZ 加分。
- WebSocket 地址可修改；旧连接回调按来源令牌丢弃，换来源会切断原局观测连续性，谱面背景缓存同时按来源隔离。Windows 自定义版的互斥名、启动入口、端口、会话目录与启动器设置目录独立。

行为与 main 对齐：Warm-up 仅影响显示，房间观测与正式记胜继续；已准备本图不因房间随后换图而自动替换。后者需要直播员明确重新准备，保留原 Pick 归属与后续 BP。
