# 整卡背景与参数来源

日期：2026-10-30（America/New_York）。

## 修改

- Mappool 的真实背景图铺满整个格子，序号栏为半透明，文字区加渐变遮罩；红／蓝队框位于背景与遮罩上方。Ban 整图压暗，Pick 不灰化。图片失败时保留原有占位，卡片与网格尺寸不变。
- Playing 新增 HP。正式环境仍以匹配本局谱面、房间且新鲜的 tosu 数据为唯一参数来源，CS／HP／AR／OD 使用 converted；不从官方文件自动补值。
- 只有显式的 tosu 模拟会话使用官方 `.osu` 文件的原始 CS／HP／AR／OD 与 BPM，显示「测试 · 原始参数」。模拟器合成参数即使图 ID 匹配也不会冒充实际谱面数值。测试参数不根据 HR／DT 标签推造模组转换，不推算文件未提供的星级与末物件时长。
- 文件返回的 BeatmapID 必须匹配选图；封面和参数共用限速、并发去重和缓存。变速图的原始 BPM 显示实际范围，缺失、空值、非数值保持未知，真实 0 保留。切图立即清空旧参数，取消旧请求，迟到结果不会写回新图。

参数一直为「—」的实际原因：检查时本局为 HR1（2477308），模拟 tosu 仍在池外 799999，左右房间也不匹配；原同图／同房间保护生效。未更改原比赛的房间绑定、谱面或游戏信号来强行满足条件。

字段来源：[osu! 官方文件格式](https://osu.ppy.sh/wiki/en/Client/File_formats/osu_(file_format))。原始值与 tosu 转换值是独立口径。
