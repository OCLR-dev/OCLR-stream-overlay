# tosu 房间自动读取

2026-10-30。仅 main；未修改自定义测试工作区。

- 控制台移除客户端“已核对”选择、房间左右队名输入，直接显示 tosu 实时读数。三个自动跟随开关保持独立。
- 服务端从有效 tourney / IPC 帧自动读取左右队名，替换空白或过时的手填绑定，不覆盖赛事队伍资料、名单、图池、BP、每局记录或系列分，也不额外占用撤销步骤。
- 实时队分和聊天直接使用当前连接的房间数据。过期、断线、无赛事数据时不保留旧实时值；首次 Playing / Ranking 不补记旧赛果。实际观测中更换房间仍中断原局结算连续性，新队名继续自动读取。
- 离线模拟重置可重试自动读取队名引起的版本冲突，保持原命令 ID，避免重置与遥测交错导致失败。

验证：类型检查、生产构建、diff 检查通过；完整 199 项测试全部通过。新增覆盖无手填绑定的真实 WebSocket 接入、过时名称与待记录结算恢复、明确暂停和自动化关闭、同名左右队伍、撤销步骤及不补造旧赛果。现有结果去重、纠错、BP、断线恢复和便携服务测试保留。

本机服务恢复为 3001 / 24051，赛事来源仍为真实只读 API，现有比赛、图池、BP、系列比分和逐局记录与重启前一致。恢复的模拟房间处于 Ranking（IPC 4），无异常；不会自动回放已经结束的演练。后续 Ranking 总分显示修正见 [Ranking 总分](../ranking-total-score/README.md)，Playing 与 Ranking 均可显示当前队分。
