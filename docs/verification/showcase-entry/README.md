## 原因与行为

原控制台没有通往 `/showcase` 的按钮；场景创建仅在该页面的折叠 OBS 设置内。底层已实现不等于直播员能从控制台找到并完成操作。

- 控制台左侧保留「比赛现场／开播前设置」页签，右侧将独立 Showcase 按钮与观众画面入口成组。窄屏分为两行，按钮保留图标与文字。
- Showcase 使用独立页面，页首提供返回控制台按钮；导航不改变比赛播出场景或自动化。
- OBS 设置移到 Showcase 页首并直接显示；连接后展开场景操作，明确标示「创建 OCLR · Showcase 场景」及完成提示。
