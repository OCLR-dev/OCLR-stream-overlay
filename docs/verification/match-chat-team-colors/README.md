# Match Chat 选手 ID 队伍颜色

直接使用 tosu v2 聊天消息的 `team`：left 为现有红队色，right 为现有蓝队色；其他值或缺失字段保留中性紫色。只给发言者名称着色，正文、消息顺序与 Stream Chat 不变。后续快照更新队伍字段时，已显示消息的名称颜色同步更新。

验证：`npm run build` 通过；1920×1080 隔离浏览器检查红蓝名称、裁判／机器人中性色、已有消息换队后颜色更新、正文不变、none／缺失值回退、Stream Chat 留空，全部通过，无页面异常。见 [预览](teams.png)。

预览使用合成聊天消息，未接入真实 tosu／OBS；真实 Windows 换位与聊天联调仍待现场验证。
