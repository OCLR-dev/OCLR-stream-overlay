## 使用流程

1. 核对系列赛制与比分。主版 BO11 为 5:5、BO13 为 6:6；自定义版按实际 BO，例如 BO9 为 4:4。BO 未配置、比分未到条件、未核对的在场赛果、暂停或本图异常均不开放准备。未知历史不补造；已存在的待处理赛果需先核对。
2. 图池管理在红蓝队 Ban／Pick 按钮下方常驻一整行「TieBreaker」。点击即使用本场唯一 TB 条目准备，无需展开、手选谱面或指定 Pick 方。缺少或存在多张 TB 时先在开播前设置确定唯一决胜图；条件不足时按钮禁用。Playing 的普通准备表单不再列出 TB，已准备 TB 时隐藏该表单。
3. 普通图误准备时先通过原有调整入口作废，再准备 TB。TB 不经普通 BP，也不追加 Ban／Pick 历史；保留待处理的普通动作以供撤销恢复。谱面变化不能代替比分校验。
4. TB 清除已开启 EX，双方恢复常规人数，EX 次数保留；不能 Ban、标记为某队 Pick 或通过图池设置转换已有局的普通／TB 类型。图池显示「决胜图」，Playing 保留原有 TB 与实际 MOD 参数链路。
5. 有效新开打／结算沿用现有自动跟随与一次计胜；可人工记胜、修正、撤回、系列比分校正及裁判重赛。TB 结束不推进普通 Pick，Winner 继续由直播员展示。准备后比分改离决胜条件会阻止开打 TB。
