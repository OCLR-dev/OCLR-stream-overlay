# 控制台、共享会话与自动流程验证

日期：2026-10-28（America/New_York）。本 Mac 没有 tosu。真实 API 资料读取、浏览器检查与合成 tosu 状态序列分别记录，均不代替直播机联调。

## 已实现

- `/control` 与 OBS 的只读 `/overlay` 为独立页面。服务器快照/SSE 同步同一会话，输出无按钮、不受旧 hash 场景控制；根路径保留视觉演示。
- 到场、真实 Roll 与独立先手、明确 BP 动作/序列、单图 Ban/Pick、准备图替换、Playing、单图结算、Winner、暂停与恢复。
- 唯一服务端 tosu 观察器；换图绑定当时动作并去重，首次连接/重连/锁定/暂停恢复建立基线。未匹配图、重复槽位、错误房间不推进。
- 连续 Playing → Ranking 自动展示结算，稳定完整且不相等的最终队分自动增加赢图。每局只加一次，晚到分数可在同一连续结算中补齐；未知/平分保留人工处理。
- 撤回本局计胜、修正胜方、绝对系列比分校正、作废/独立重赛、最近变更撤销。旧结算不会覆盖人工纠错；校正后的比分继续累计新赢图。达到目标后人工展示 Winner。
- 串行命令、版本冲突、命令 ID 去重、原子持久化、本机存档；实时状态和观察器连续性不从磁盘恢复为 live。

用户明确允许使用 S10/S9 等历史资料验证。本轮实际读取 S10 的同一份公开归档：10 队、80 位选手、5 图池、36 条场次记录。现代 `/teams`、`/mappools` 为空；明细来自 `/configuration` 的 `edition.archive`，已单独映射。

现有本机 Bearer 凭证返回 `INVALID_TOKEN`，该验证服务保持 blocked 并清空来源。随后另起**明确匿名模式**的公开资料验证服务，未更改 `.env.local` 或凭证文件、未让 Bearer 服务自动降级。正式使用前需更新 Key 或明确选择公开匿名配置。
