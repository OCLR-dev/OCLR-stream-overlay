# 本图异常、重赛与观战恢复

导播在「处理异常」中按现场看到的情况选择操作。等待核对会保留本局记录，裁判决定重赛后再准备同一张图的新尝试。

| 现场情况 | 系统与导播的操作 |
| --- | --- |
| 已 Pick，游戏未能开打 | 保留选图、BP 和 EX，等待原图开打。 |
| 已观察到开打，随后连续回到同一房间的准备状态，期间未到 Ranking | 系统将未完成的尝试作废，恢复原图准备，保留当前画面、BP、EX 和系列比分。 |
| 有人卡住，房间仍在 Playing | 点「有人卡住，先等一下」挂起本局自动计胜。裁判决定继续原局后接回；若裁判宣布重赛，用「裁判已要求重赛本图」。 |
| 直播端观战窗口重载 | 同一局、同一谱面和选手的有效 Playing 信号恢复并通过核验后，系统可接回原局。断线期间已经结束的图按裁判确认的结果人工记录。 |
| 自动加分后成绩仍在变化 | 系统可撤回该图的自动贡献并提示核对。在 Playing 核对最终队分后记录胜方。 |
| 已经记胜，裁判要求重赛 | 点「裁判已要求重赛本图」，系统撤回原尝试的计胜和相应 EX 消耗，保留该次 Pick 与后续 BP。曾直接改过系列分时一并核对比分。 |

「暂停播出」控制播出画面，处理异常控制本局是否可以计胜。导播可以单独使用。恢复或重连后从新收到的有效比赛数据接续。上一次 Ranking 不会重新计胜。
