# OCLR Windows 直播员操作手册

适用环境：Windows 10 / 11（64 位 x64）。无需安装 Node.js 或 Git，全程图形界面操作。

## 开播前准备清单

| 项目 | 准备要求 |
| --- | --- |
| **OCLR 压缩包** | 包内已自带直播服务与 `tosu`，无需单独下载 `tosu` |
| **osu!stable** | 自行安装并登录 osu! 账号。建议**比赛观战（Tourney）**与**日常游玩 / Showcase** 分两个独立文件夹安装 |
| **OBS Studio** | 自行安装（建议 OBS 28 及以上，自带 WebSocket 服务与应用程序音频采集） |
| **WebView2 运行时** | Windows 10/11 通常已内置；若启动时提示缺少运行时，按弹窗提示安装后重开即可（离线电脑请提前安装） |
| **OCLR 账号权限** | 正式开播需联系赛事管理为你的 osu! 账号开通当季 **Streamer（直播员）** 权限 |

### 认识 OCLR 窗口结构

双击 `OCLR.exe` 打开 **OCLR 直播工作台**，界面分为两层：

- **窗口最顶栏（全局导航）**：
  - **直播控制台**：正赛与表演赛操作主页，页面内部分为 **「比赛现场」**（开播后操作）与 **「比赛配置」**（开播前准备）。
  - **Showcase**：图池演示与 `.osr` 回放自动过场主页。
  - **服务**：一键启动 `osu!Tourney` 与 `tosu`，查看服务状态、复制 OBS 地址。
  - **设置**：选择 `osu!.exe` / `tosu.exe` 路径、调整画质渲染、修改端口、切换便携存储。
  - **日志 / 关于 / 退出服务**：查看排障日志、版本信息，或点击最右侧「退出服务」保存比赛并停止播出。
- **放心操作原则**：切换顶栏页面、点工作区右上角「重新加载页面」或最小化窗口，**OBS 播出都不会中断**；习惯用浏览器操作可点工作区右上角「在浏览器打开」。只有点击顶栏右侧 **「退出服务」**（或关闭窗口）并在弹窗确认后，才会保存比赛并停止 OBS 画面。

> **按你的直播任务选择阅读路径：**
> - **播正赛 / 表演赛**：依次完成 **第 1 → 4 步** 开播准备，开打后看 **第 5 步** 现场操作，下播看 **第 7 节**。
> - **播图池 Showcase**：完成 **第 1 步** 启动程序后，直接跳到 **[第 6 节：图池 Showcase 演示](#6-图池-showcase-演示)**。

## 1. 下载、完整解压并启动

1. 前往 [GitHub Releases](https://github.com/OCLR-dev/OCLR-stream-overlay/releases) 下载最新版 `OCLR-Windows-x64.zip`（可选用同页的 `.zip.sha256` 校验完整性）。
2. 右键压缩包选择 **「全部解压」**，解压到任意有写入权限的文件夹。
   - 保持 `OCLR.exe` 与同级的 `app`、`runtime`、`tosu` 文件夹在同一目录，**不要**直接在压缩包内双击，也不要单独把 `OCLR.exe` 拖到桌面（可用右键发送快捷方式）。
3. 双击 **`OCLR.exe`** 启动，等待窗口自动进入「直播控制台」。
   - **Windows 安全提示**：便携包未签名。若 Windows 提示发布者未知，请先核对官方 GitHub 下载来源及发布页提供的 SHA-256 校验值。
   - **续播提示**：若弹出「继续上次的比赛？」，接着播同一场点 **「继续上场比赛」**；换新场次点 **「存档并开始新比赛」**。

## 2. 载入本场直播任务

在窗口顶栏确认处于 **「直播控制台」**，点击页面内的 **「比赛配置」**（默认打开 **「本场资料」** 标签页）：

1. **登录授权**：在「OCLR 直播任务」填写授权赛季（如 `s11`），点击 **「登录 OCLR 并连接任务」**。系统默认浏览器会自动弹出本机授权页，点击 **「前往 OCLR 授权」**，登录 osu! 账号并同意授权。完成后回到 OCLR 窗口，状态会变为「已连接，直播任务自动更新」。
   - *备用方式*：若浏览器拦截了弹窗，展开「手动复制授权（备用）」，打开直播授权页并选择与提示一致的本机地址（默认 `http://127.0.0.1:3001`），复制一次性凭证粘贴连接。重启服务或更换端口后需重新登录授权。
2. **导入本场任务**：在「直播任务」下拉框选择你的场次，核对红蓝双方、开赛时间、图池与赛制后，点击 **「使用所选直播任务」**。
   - 系统会自动填入队名、队旗和双方公开注册名单（供开场等待画面展示）。若换场前已有上一场记录，请先展开底部「管理比赛记录」点 **「初始化」** 存档上一场，再导入新任务。
3. **核对上场名单**：展开下方 **「手动编辑队伍、名单与图池」**，按每行 `用户名,UID`（UID 可省略）核对或修改本场实际上场名单，停顿后自动同步。

> **赛前无任务时如何自己练习？**
> 展开「从 OCLR 已发布资料选择」，输入历史赛季（如 `s10`），依次选择场次、图池和左右队伍即可在本机模拟操作。正式开播前，到「管理比赛记录」点「初始化」清空练习记录，再导入正式直播任务。

## 3. 启动 osu!Tourney 与 tosu

比赛房间数据通过同机运行的 `osu!Tourney` 与 `tosu` 自动读取。**请先确保第 2 步已在控制台成功连接 OCLR 授权赛季**，然后按顺序启动：

1. **首次绑定 osu! 路径**：点击窗口顶栏 **「设置」**，在「比赛工具 → osu!stable 应用程序」点击 **「选择 osu!.exe」**，选中用于比赛观战的 `osu!.exe`（确认该 osu! 当前未运行，且平时已登录过账号）。[osu!tourney 官方说明](https://osu.ppy.sh/wiki/en/osu%21_tournament_client/osu%21tourney/Setup)
2. **一键写入配置并打开 osu!Tourney**：点击窗口顶栏 **「服务」**，在「比赛工具」卡片点击 **「打开 osu!Tourney」**。
   - OCLR 会自动在所选 osu! 目录生成 `tournament.cfg`（默认 `TeamSize = 4`、高度 `1080`、`acronym` 自动填入当前授权赛季如 `OCLR S11`；若替换了旧配置会自动备份为 `tournament.cfg.oclr.bak`）并启动观战客户端。
3. **打开内置 tosu**：等 osu!Tourney 窗口完全启动后，在「服务」页点击 **「打开 tosu」**。
   - 启动器默认使用包内自带的 `tosu/tosu.exe`（端口 `24050`），看到卡片显示 **「tosu 正在运行 · 端口 24050 可连接」** 即表示就绪。
4. **进房核对连接**：在 osu!Tourney 进入裁判创建的本场 MP 房间。点击窗口顶栏回到 **「直播控制台」**，切到 **「比赛配置 → 游戏数据」**：
   - 确认状态显示已连接，且读出房间当前左右队名（房间队名由 tosu 自动同步，无需手填）。
   - 下方三个开关（**自动 Ban / Pick**、**自动切换画面**、**自动计胜**）保持默认开启即可。

## 4. 配置 OBS 场景、声音与弹幕

### 4.1 一键创建比赛场景

1. 打开 OBS Studio：
   - 在 **「设置 → 视频」** 将**基础（画布）分辨率**设为 `1920×1080`。
   - 在 **「工具 → WebSocket 服务器设置」** 勾选「启用 WebSocket 服务器」和「启用身份验证」，查看服务器端口（默认 `4455`）并设好密码，点确定。
2. 回到 OCLR **「直播控制台 → 比赛配置 → OBS」**，输入 OBS 端口与密码，点击 **「连接本机 OBS」**。
3. 选择本场 **「游戏源比例」**（常规选 `4:3`，宽屏客户端选 `16:9`），点击 **「创建比赛场景」**。
   - OCLR 会在当前 OBS 场景集合中自动建好 **「OCLR · 常规 4v4」** 和 **「OCLR · EX 3v3」** 两套场景（共用顶层观众画面与八路捕获源，场景项默认锁定防误拖，需要微调时点 OBS 来源旁的锁图标即可；误删场景可再点一次补建；使用自建场景也可直接在下拉框绑定并勾选 **「OBS 跟随 EX」**）。

### 4.2 核对捕获窗口与游戏音频

1. **核对八路画面**：在「OBS → 场景与捕获窗口」查看 `A1–A4`（对应左队红方 Client 0–3）与 `B1–B4`（对应右队蓝方 Client 4–7），确认全部显示 **「已绑定」**。若显示「未找到」或「有歧义」，确保八个客户端窗口已打开且无重名窗口，点 **「重新识别窗口」** 或在下拉框手动补选。
2. **核对游戏声音**：
   - Windows 新版 OBS 会自动创建共用音源 **「OCLR · osu!tourney 音频」**，自动抓取唯一的 `Tournament Client 0` 声音（切换 EX 时依然保持发声）。
   - 在客户端随意播放一首曲目，观察 OBS「混音器」中该音轨绿条是否正常跳动、未静音。
   - **防重音检查**：若你的 OBS 同时开着全局「桌面音频」，混音器会收到两份游戏声，请将全局桌面音频静音；如果你手动使用桌面音频作为游戏声来源，先确认直播混音器中只有一路在采集游戏声音。

### 4.3 配置 B 站直播间弹幕（可选）

1. 用开播账号登录 [B 站互动玩法](https://play-live.bilibili.com/)，在页面底部复制 12–14 位 **「身份码」**（详见 [blive.chat 图文教程](https://blive.chat/help)）。
2. 在「比赛配置 → OBS」底部的 **「B 站直播间弹幕」** 粘贴身份码，系统会自动在常规和 EX 两套场景右下角 `STREAM CHAT` 框内配好共用的弹幕浏览器源（左侧 `MATCH CHAT` 自动显示 osu! 房间聊天）。
   - 下次更换直播间时，点「更换身份码」粘贴新码即可。身份码保存在本机当前场景集合中；如需把 OBS 场景集合导出分享给他人，请先删去该弹幕源中的网址。

### 4.4 开播前最后自检

点击右下角 **「进入比赛现场」**，若 OBS 当前还在其他场景，点右侧缩略图下方的 **「切回当前比赛布局」**。
首次在这台电脑接线时，建议开播前在 OBS 本地试录 30 秒（常规 4v4 → 点开某队 EX 切到 3v3 → 关闭 EX 回到 4v4），确认八路选手画面对齐、Playing 到结算（Ranking）窗口不断裂、游戏有声且无双重回声、直播间弹幕正常显示。

## 5. 比赛现场怎么播（导播操作流）

进入 **「直播控制台 → 比赛现场」** 后，界面左右分工明确：

- **左上「当前步骤」卡片**：实时提示当前所处阶段和下一步该点什么，拿不准时看这里即可。
- **左下操作面板**：跟随当前选中的画面自动切换（例如切到 Roll 就显示填点数，切到图池就显示点选 BP，切到 Playing 就显示实时队分与赛果确认）。
- **右侧监看与快捷栏**：连接 OBS 后定期刷新 **OBS 节目画面（Program）** 缩略图及推流/录制状态；下方提供 `Alt+1` 至 `Alt+5` 五个画面切换键（`等待`、`Roll / 先手`、`图池 / BP`、`Playing`、`Winner`）以及正赛 **「本图 EX」** 控制卡。
- **自动跟随省心机制**：默认全程开启。只要完成初始先手确认，收到有效房间数据后，控制台会按启用的自动跟随设置识别换图、开打和结算。即使你中途手动点了其他画面（状态提示“手动保持画面”），下一次有效游戏事件发生时也会自动接回。

### 5.1 标准正赛五步流程

1. **开场等待与热身（`等待` 画面）**
   - 双方进房后可勾选左右队的「已到场」「已就绪」。
   - 若赛前打热身图，点击顶部工具栏 **「Warm-up」**：观众画面会隐藏系列比分与赢图槽，同时正常展示实时曲目（`Now Playing`）与队分；热身结束后再点一次「Warm-up · 开启中」关闭，点击 **「开始 Roll →」**。
2. **记录点数与先手（`Roll / 先手` 画面）**
   - 输入双方 Roll 点数，下拉选择 **「Roll 胜方」**、**「先 Pick」**、**「先 Ban」**（正赛先 Ban 与先 Pick 可按规则选同一队；表演赛仅需选先 Pick），点击 **「进入图池 / BP →」**。
3. **图池禁选（`图池 / BP` 画面）**
   - 轮到某队操作时，直接点击下方图池中的谱面卡片并确认推荐动作；也可以点右上角 **「先选动作」** 进入点图模式，再点谱面或等待裁判在房间换图自动识别。某队放弃 Ban 图时点 **「空 Ban」**。
4. **开启本图 EX（仅正赛 4v4 普通图开打前）**
   - 若某队声明本图开启 EX，**在开打前**于右侧「本图 EX」点击 **`[队名] 开启 EX`**（OBS 会自动切到 `OCLR · EX 3v3` 六路场景）。
   - **席位要求（务必核对）**：保持八个 osu!tourney 客户端不关，请裁判将本图上场的 6 名选手排入 **左队红方 Client 0–2（A1–A3）、右队蓝方 Client 4–6（B1–B3）**，并让 **Client 3、7 留空**（系统固定按这六路重算实时与结算队分；「EX 实际上场的六路」用于调整 OBS 捕获窗口，计分固定使用上述六个 Client）。
   - 本图正常结算记胜后会自动扣减 1 次 EX 剩余次数；下一图若不开 EX，在准备期点击 **「关闭 EX」** 切回常规 4v4。
5. **Playing、单局计胜与全场 Winner**
   - **Playing 与结算**：游戏开打自动切入 `Playing`，打完进入 Ranking 时在原窗口位置保留结算成绩。系统连续观测到完整稳定的最终队分后，**每局自动计胜一次**（FM 图自动按规则计入 EZ 1.5 倍队分补偿）。若因观战波动未自动记分，在左侧展开「待确认赛果」按裁判确认结果手动点击记胜（支持表演赛记录平局）。
   - **决胜图 TB**：正赛双方打到赛点平（如 BO11 的 `5 : 5`）时，在图池面板点击 **「TieBreaker · 准备决胜图」**（自动恢复常规人数）。
   - **展示 Winner**：当一方达到目标赢图数后，点击左上或 Playing 面板的 **「展示 [队名] Winner →」** 切入全场战报画面。

### 5.2 现场突发状况速查（救场指南）

| 现场状况 | 在控制台怎么操作 |
| --- | --- |
| **比赛已经开打，我中途才来接播** | 直接让 osu!Tourney 进房并打开 tosu！无需补录之前的 BP，切到 `Playing` 即可立即播出实时队名、谱面与队分。展开 Playing 下方的 **「校正系列比分」** 把大比分改对，等本局打完后从图池指定下一张图的当前动作即可继续自动跟随。 |
| **需要暂停休息 / 切广告** | 点击顶部工具栏 **「暂停画面」**（可选普通、技术、战术暂停并启动倒计时；倒计时归零不会强行切回，现场就绪后点「启动 10 秒即将开始」或「返回原画面」）。若你在 OBS 手动切去了自建广告场景，返场时点右侧缩略图旁的 **「切回当前比赛布局」**。 |
| **有人掉线卡住 / 观战黑屏 / 裁判判重赛** | **切勿点初始化！** 点击顶部工具栏 **「处理异常」**：选「有人卡住，先等一下」或「直播画面异常」可挂起自动计胜防止误加分；恢复正常点 **「观战已恢复，继续原局」**；裁判明确判重赛则点 **「裁判已要求重赛本图」**（保留原 Pick 与后续 BP，撤回本局 EX 消耗）。 |
| **裁判房间换错了谱面** | 准备期左上「当前步骤」会提示房间图与已选图不一致，若是临时改选可直接点 **「改为房间当前谱面」**。 |
| **刚点错了 BP 或记错了本图胜方** | 刚发生的操作直接点顶部工具栏 **「撤销上一项」**；图池面板也可点「撤回上步 BP」，Playing 面板「上一局赛果」可直接点 **「改为 [另一队] 胜」** 或 **「撤回本图赛果」**。 |
| **要改更早之前的 Ban、先手或单局记录** | 点击顶部工具栏 **「比赛纠错」**（或展开页面底部的「比赛纠错」折叠栏），可独立修改真实 Ban 1/2、当前 Pick 方、Roll 先手、EX 剩余次数或任意历史单局胜方，不影响当前正在进行的比赛。 |

## 6. 图池 Showcase 演示

> **客户端区分（重要）**：Showcase 使用 **普通 osu!stable 客户端** 单窗口播放 `.osr` 回放，**不能**使用带 `tournament.cfg` 的比赛客户端（否则会被识别为赛事模式）。建议单独准备一份干净的普通 osu!stable 目录，并提前装好本轮图池全部谱面。

### 6.1 导入演示图池与预缓存回放

1. **启动普通客户端与 tosu**：在窗口顶栏 **「设置 → 比赛工具」** 点击 **「选择 osu!.exe」**，选中**普通 osu!stable** 的 `osu!.exe`。先手动打开这个普通 osu!，再到窗口顶栏 **「服务」** 点击 **「打开 tosu」**。
2. **进入 Showcase 页面**：点击窗口顶栏 **「Showcase」**，在「当前 Stage」输入轮次标题（如 `32强`、`半决赛`、`决赛`，留空则隐藏）。
3. **导入图池**：在「演示图池」可通过三种方式载入：
   - **从 OCLR 网站导入（正式未公开图池）**：在「从 OCLR 网站导入」填写赛季并点 **「登录 OCLR」**（已登录直播控制台时会自动复用授权），选择管理员已锁定并授权给你的图池，点 **「导入到 Showcase」**。
   - **复用或手动录入**：也可点「复制控制台已加载图池」，或在底部文本框按每行 `Slot 谱面ID`（如 `NM1 123456`）手动粘贴，停顿即自动同步。
4. **核对并缓存 `.osr` 回放**：
   - 网站图池导入后会自动读取回放清单。若当前网站设有独立的回放读取开关，请管理员开启。网站只提供每个 Slot 的首选回放。补传、删除或更换首选回放会更新图池版本，请管理员重新授权新版后点「刷新图池」重新导入。
   - 单份回放自动选中，若同一行有多份可用回放，可在下拉框选择；缺件可直接把本地 `.osr` 文件（最大 8 MiB）拖进对应谱面行，或点 **「选文件」** 补齐。
   - **强烈建议**：正式开播前点击 **「提前缓存回放」**，等待各行显示 **「已缓存」**（失败项可再点一次重试，持续失败时补入对应的本地原件），避免直播途中临时下载卡顿。

### Showcase 回放过场

1. **创建 OBS 场景与过场美术**：
   - 在 Showcase 左侧「OBS 场景」连接本机 OBS，点击 **「创建 OCLR · Showcase 场景」**，随后点击 **「启用自动过场」**（若此前建过旧版纯色遮罩，点 **「更新过场美术」**）。
   - 如需显示 B 站弹幕，同样在下方「B 站直播间弹幕」粘贴身份码即可自动复用。
2. **摆放普通 osu! 捕获图层**：
   - 在 OBS 切到 `OCLR · Showcase` 场景，手动新建一个抓取普通 osu! 客户端的「游戏捕获」或「窗口捕获」源。
   - **核对上下层级（从上到下）**：
     1. 最上层：`OCLR · Showcase 过场美术` 与遮罩源（保持在最顶层，换图加载时自动盖住游戏区并展示深紫斜幕、下一张图卡与进度条，右侧弹幕保持可见）
     2. 中间层：**你添加的普通 osu! 捕获源**（缩放到画面中央 `1600×800` 区域内等比居中）
     3. 最底层：`OCLR · Showcase` 背景浏览器源（`1920×1080` 铺满画布）
3. **正式播出操作循环**：
   - 在 OBS 将 `OCLR · Showcase` 切入**节目画面（Program）**。
   - 看到演示图池状态提示 **「遮挡已确认」** 后，点击 **「播放下一张」**（如需跳播某张图，先在该行点 **「设为下一张」**）。
   - OCLR 会自动调用普通 osu! 打开该回放，提示「等待 osu! 开始回放」；检测到目标回放开始推进后，**过场斜幕自动揭开**。
   - 回放打完进入结算页后，画面会保留展示成绩 **3.5 秒**，随后**自动重新盖上过场斜幕**。再次显示「遮挡已确认」后，继续点 **「播放下一张」** 或 **「重播本张」**，直至播完整个图池（同图重播不会重复增加进度计数）。
4. **过场应急接管**：
   - 若回放未打开或进错谱面：检查普通 osu! 与 tosu 连接后原位重试。
   - 若中途从休息/广告场景切回：先在 OBS 切回 `OCLR · Showcase`，等「遮挡已确认」后再点播放。
   - 若需人工强行揭幕：先在 OBS 预览确认游戏画面安全，点击「OBS 场景 → 回放过场」下的 **「确认画面安全，手动显示」**；点 **「立即遮挡」** 可恢复自动过场。

## 7. 下播收尾、存储与版本更新

### 7.1 导出录像打点与安全下播

1. **复制录像时间轴（如有开启 OBS 录制）**：
   - 比赛录制期间，每局实际开打、同图重赛及全场结果确认时，OCLR 服务都会自动记录录像时间码；遇到高光操作也可随时点右侧的 **「标记精彩时刻」**。
   - 比赛结束并在 OBS **停止录制**后，在「比赛现场」右侧展开 **「录像打点」**，点击 **「复制时间轴」** 粘贴保存到本地文本中，方便赛后剪辑或发视频分 P。
2. **退出服务或准备下一场**：
   - **连播下一场**：在 Winner 面板点击 **「存档并准备下一场」**（或在 `比赛配置 → 本场资料 → 管理比赛记录` 点 **「初始化」**），上一场会自动存档，随后按第 2 步导入新任务即可。
   - **结束今日直播**：点击窗口顶栏右侧 **「退出服务」**（或窗口右上角关闭按钮）并在弹窗确认。OCLR 会完整保存当前比赛进度并停止 OBS 网页输出（下次打开可恢复；已运行的 osu! 与 tosu 不会被强关，可自行关闭）。

### 资料存储与更新

#### 两种资料存储位置

可在窗口顶栏 **「设置 → 资料存储」** 查看当前路径或切换模式（切换时会先保存比赛并退出 OCLR，重新打开后生效）：

- **默认模式（Windows 用户目录）**：保存在 `%LOCALAPPDATA%\OCLR`。其中 `StreamOverlay` 存放比赛记录、Showcase 配置、OBS 设置、历史存档备份与录像时间轴（`recording-timelines`）；`StreamOverlayLauncher` 存放工具路径（`settings.json`）、服务端口（`service-port.txt`）、运行日志（`launcher.log`）及 WebView2 缓存。
- **完全便携模式（随程序文件夹走）**：点击 **「启用完全便携模式」** 后，首次启用会将现有设置与比赛复制到 `OCLR.exe` 同级的 **`OCLR-data`** 文件夹，并生成 `OCLR-portable` 标记文件（原用户目录资料仍保留，两处后续各自独立保存）。适合装在移动硬盘或整包迁移。

#### 如何更新 OCLR 版本

1. 先正常点击「退出服务」关闭旧版 OCLR。
2. 将新版 `OCLR-Windows-x64.zip` **完整解压到一个新文件夹**（不要直接覆盖旧版文件夹）。
3. 按你使用的存储模式启动：
   - **默认模式**：直接双击新版 `OCLR.exe`，自动读取本机原有设置与比赛。
   - **完全便携模式**：将旧版文件夹里的 **`OCLR-portable` 文件**和 **`OCLR-data` 文件夹**一起复制到新版 `OCLR.exe` 旁边，再双击启动。（若你手工改过随包 `tosu/tosu.env` 的配置，可按需将该文件复制到新包 `tosu/` 目录。）
   - *附：极早期纯 Node 版本迁移*：先退出旧服务，把旧项目的 `.local` 文件夹复制到新版 `OCLR.exe` 旁边再首次启动，程序会自动备份并迁移旧记录。

## 8. 进阶设置与手动接线（按需查阅）

### 8.1 修改服务端口、自定义 tosu 与 4K 渲染

均在窗口顶栏 **「设置」** 中操作：

- **修改本机端口（默认 `3001`）**：在「直播服务 → 本机端口」输入 `1–65535` 的整数，点击 **「重新启动」**。已连接 OBS 时会自动将当前场景集合中的本机 Overlay / Showcase 浏览器源同步为新端口；重启后需重新登录 OCLR 授权。（注：若使用「手动复制授权」，网站若限制了本机授权来源，请管理员核对所用地址与端口是否在允许列表中。）
- **使用自备的 tosu**：在「比赛工具」点 **「选择 tosu.exe」**。有效的自定义路径优先于包内版本（路径失效时自动回退包内 `tosu/tosu.exe`）。启动器会自动读取所选程序同目录 `tosu.env` 中的 `SERVER_PORT` 并同步给控制台。
- **开启高分辨率渲染（默认关闭）**：勾选「比赛画面 → 高分辨率渲染」后，OCLR 管理的常规与 EX 比赛场景会将浏览器源升级为 `3840×2160` 渲染并等比适配至 `1920×1080` 画布，文字与边缘更锐利。切换时会短暂刷新浏览器源，请在开播前或场间操作。

### 8.2 手动添加 OBS 浏览器源（不使用一键创建场景时）

若你有特殊的自建 OBS 场景、不打算使用「创建比赛场景」，可按以下参数手动配置：

| 用途 | 默认地址（改端口后以「设置 → 复制全部地址」为准） | 尺寸与位置 | 关键属性 |
| --- | --- | --- | --- |
| **比赛观众画面** | `http://127.0.0.1:3001/overlay` | 宽 `1920`、高 `1080`，位置 `(0, 0)` | 置于所有游戏捕获源**上方**；**取消勾选**「不可见时关闭源」和「场景激活时刷新」；Playing 窗口原生透明，**无需加色键滤镜** |
| **Showcase 播出底板** | `http://127.0.0.1:3001/showcase?clean=1` | 宽 `1920`、高 `1080`，位置 `(0, 0)` | 置于普通 osu! 捕获源**下方**；普通 osu! 捕获在中央 `1600×800`（左上角 `160, 100`）区域内等比居中 |

手动摆放比赛各路游戏捕获时，缩放设为 `1:1`、裁切为 `0`：
- **4:3 游戏源**：每路宽 `480`、高 `360`，左上角坐标按下表摆放。
- **16:9 游戏源**：每路宽 `480`、高 `270`，在原行内垂直居中（即下表中所有 `y` 坐标统一 **`+45`**，第一排 `y = 225`，第二排 `y = 585`）。

| 布局 | 槽位 | 左队红方左上角 `(x, y)` | 右队蓝方左上角 `(x, y)` |
| --- | --- | --- | --- |
| **常规 4v4 / 3v3 共用上排** | 第一路（A1 / B1） | `(0, 180)` | `(960, 180)` |
| **常规 4v4 / 3v3 共用上排** | 第二路（A2 / B2） | `(480, 180)` | `(1440, 180)` |
| **常规 4v4 下排** | 第三路（A3 / B3） | `(0, 540)` | `(960, 540)` |
| **常规 4v4 下排** | 第四路（A4 / B4） | `(480, 540)` | `(1440, 540)` |
| **3v3 / EX 3v3 下排居中** | 第三路（A3 / B3） | `(240, 540)` | `(1200, 540)` |

*注：如需精确核对 OBS 内各图层的实际像素参数，可在控制台 `比赛配置 → OBS → 核对 OBS 原始尺寸与位置`（确保两套场景均已显示过游戏画面，否则 OBS 可能将未激活源宽高报为 0）点击「读取两套场景」。*

## 9. 常见问题排障

| 看到的现象 | 原因与处理办法 |
| --- | --- |
| **提示缺少运行文件 / 双击打不开** | 未完整解压。请重新对 `.zip` 右键「全部解压」，确保 `OCLR.exe` 旁保留完整的 `app`、`runtime`、`tosu` 文件夹；提示缺少 WebView2 时按弹窗安装。 |
| **启动提示端口被占用 / 已有其他版本运行** | 电脑上已开着另一个 OCLR 或其他程序占用了 `3001` 端口（重复双击 `OCLR.exe` 会自动回到已打开的窗口）。请先退出旧程序，或在窗口顶栏「设置 → 直播服务」换一个端口再点「重新启动」。 |
| **启动提示「比赛记录无法读取」** | 本机存档文件异常。程序为保护现场不会覆盖原文件，**请勿手动删除数据或点初始化**；到窗口顶栏「日志 → 打开完整日志」保存 `launcher.log`（超过 1 MiB 会附带 `launcher.log.1`，发送前请留意是否含个人路径隐私），连同存储目录交给维护人员排查。 |
| **桌面控制台空白、卡在加载或等待响应** | 点工作区右上角 **「重新加载页面」**，或点 **「在浏览器打开」** 用系统浏览器继续导播（同一本机服务，OBS 播出不受影响）。若状态显示「服务已停止」，点「重试启动」或查看「日志」。 |
| **点「打开 osu!Tourney」提示先连接赛季或正在运行** | ① 先到「直播控制台 → 比赛配置 → 本场资料」登录并连接当季 OCLR 授权（生成 `tournament.cfg` 需要读取赛季名）；② 完全关闭当前已运行的同目录 osu! 后再点。 |
| **tosu 显示运行中，但控制台读不到房间数据** | 确认 `osu!Tourney` 与 `tosu` 在同一台电脑运行，且客户端**已经进入 MP 比赛房间**（停留在大厅或单人模式不会产生赛事房间数据）。若先开了 tosu 后开游戏读不到，关掉 tosu 重新在「服务」点一次「打开 tosu」。 |
| **OBS 里的比赛画面卡死、黑屏，或显示成了操作后台** | ① 确认 OCLR 窗口没有被退出；② 检查 OBS 浏览器源网址是否为 `http://127.0.0.1:3001/overlay`（**不要**填成 `/control`，网址末尾也**不要**带 `#scene` 等后缀）。 |
| **OBS 里没有游戏声音，或声音有双倍回音** | 无声：检查混音器中「OCLR · osu!tourney 音频」是否未静音，且 `Tournament Client 0` 窗口已正常打开（无重名窗口）。双倍回音：OBS 全局「桌面音频」与 `osu!tourney 音频` 同时在收音，将全局桌面音频静音即可。 |
| **历史资料列表为空或读取失败** | 检查网络连接（离线启动程序没问题，但拉取线上赛事资料需联网），也可在「比赛配置 → 本场资料 → 查看维护详情」查看「赛事资料」连接状态。 |
