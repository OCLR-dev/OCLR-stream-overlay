# 比赛现场操作与中途加入

中途接手时，先看「比赛现场」的 Now Playing、左右队名和实时队分。打开或刷新控制台会读取当前比赛。进入有效的赛事房间后，即可在 Playing 播出游戏和 Ranking。

## 自动读取房间

| 现场需要 | 系统依据 |
| --- | --- |
| 显示队名、谱面、聊天与实时队分 | 队名从 tosu 房间读取。谱面、背景和聊天使用各自最新的有效数据；队分取有效 Playing／Ranking 读数。可以先播已经开打的比赛。 |
| 接手 Ban/Pick | 从已载入的图池指定当前队伍和动作。早先的禁选留空。 |
| 自动计胜 | 需要已有本局、正确的谱面与开打记录，以及连续观测到的结算和通过核验的最终队分。中途首次看到 Ranking 时，由导播核对裁判确认的结果。 |

换到另一个房间时，显示队名随之更新，队伍身份、图池和已记比分仍属于载入的本场。上一房间未结算的成绩交由现场核对。三个跟随开关可在「比赛配置 → 游戏数据」分别调整。

## Roll、选图与 TB

- **Roll。** 在 Roll 面板修正点数，平点或缺少点数时先手待定。正赛的先 Ban 和先 Pick 分别指定，可以同队。手动切画面用预览下方五个按钮或 `Alt+1` 至 `Alt+5`。
- **Ban/Pick。** 在图池点谱面，再选队伍与动作；也可点「先选动作」，再点谱面或等房间推图。已有行动顺序时，提前操作会将对应步骤移到队首，其余待办保持相对顺序。中途加入时可直接指定当前 Pick。
- **换错谱面。** 当前步骤会同时列出已选图与房间图。准备期若能唯一匹配可用条目，点「改为房间当前谱面」修正原 Pick，保留选图方、EX 和后续 BP。若已经开打，按当前步骤核对。完整观察到该图结算后可确认已结束，再处理胜方。
- **改错 Ban。** 在「比赛纠错 → 真实 Ban 记录」改对应队伍的 Ban 1 或 Ban 2，保留其他槽位和已有局次。正在 Playing、已打图、暂停或系列已结束时，仍可修正播出标记。真实 Ban、当前 Pick 与播出标记各有对应入口。
- **EX。** 正赛普通图准备期间可手动选择开启方，双方各减少一路游戏窗口。一次 Pick 正常决出胜负后扣一次，改胜方保留已扣次数，明确重赛撤回原尝试的消耗。
- **TB。** 正赛双方均达到先胜目标减一（例如 BO11 为 5:5），核对待处理赛果后点「TieBreaker · 准备决胜图」。使用本场唯一 TB，恢复常规人数。表演赛按本场规则和裁判决定准备 TB。

房间已选首图时，确认先 Pick 后可继续等待自动跟随。服务端会等准备状态稳定再确认该图。

## 暂停、异常与赛果

Warm-up 用于热身播出显示，隐藏系列比分与赢图位；比赛观测与正式计胜继续。普通、技术和战术暂停从工具栏进入。暂停倒计时到零后由导播返场；另点「即将开始」可在十秒后自动返回。

Playing 的「比分与赛果」用于核对本图、记录胜方或赛制允许的平局。可撤回本图计胜、修正胜方，也可在「比赛纠错」校正系列比分或较早的逐局记录。观战中断或裁判要求重赛时，按[本图异常处理](design/match-incidents.md)恢复。全场满足赛制条件后，由导播展示 Winner；允许全场平局的表演赛可确认平局。

## OBS 节目画面与录像打点

- 连接 OBS 后，到「比赛现场」看「OBS 节目画面」。这里约每两秒更新节目场景名和缩略图，并显示推流与录制状态。工作室模式下以 Program 为准。休息或广告结束后，在缩略图旁点「切回当前比赛布局」。
- OBS 未连接时显示「Overlay 预览」。已连接但显示「暂时读不到画面」时，在 OBS 的 Program 监看。
- 在 OBS 开始录制。tosu 观察到房间从准备进入 Playing 时，直播服务自动标记开打或同图重赛。提前切画面或准备重赛时，时间轴会等游戏实际开始。全场结果确认时也会自动打点，包括表演赛平局。中途接入从下一次观察到的事件开始。关闭控制台网页期间，直播服务继续打点。
- 录制中点击「标记精彩时刻」。停录后展开「录像打点」，点击「复制时间轴」，用时间码在对应录像中定位。暂停录制期间跳过打点，重新开始录制会另起一组。「重新接入」表示服务在录制中恢复了 OBS 连接。
- 每场打点保存在会话数据目录的 `recording-timelines` 子目录。刷新或重启后，继续同一场即可查看。备份时把该目录与录像一起保留。

## 清空记录与换场

| 目的 | 操作和结果 |
| --- | --- |
| 用同一套资料重新开始 | 「比赛配置 → 本场资料 → 管理比赛记录 → 全部撤销」。清除比分、Roll、BP、逐图记录及此前操作，回到开场等待。保留队伍、名单、图池和自动跟随设置。可以用「撤销上一项」恢复一次。 |
| 存档并换到新比赛 | 同一处点「初始化」，或在 Winner 面板点「存档并准备下一场」。当前比赛先存档，再建立新会话，可撤销。 |
| 中途初始化后继续播正在进行的房间 | 在初始化对话框选择「保留当前房间连接与自动跟随设置」。有效游戏数据到达后接回实时画面，过去的赛果留待核对。 |

启动时若检测到已保存的比赛，可选择「继续上场比赛」沿用进度，或「存档并开始新比赛」换场。
