# main：自由操作与中途加入

2026-10-30（America/New_York）。本页是当前操作口径；旧方案和验收记录保留历史，不再要求直播员从比赛第一步开始。

## 三条独立路径

| 路径 | 所需条件 | 缺少比赛历史时 |
| --- | --- | --- |
| 实时显示 | 已同步、tosu live、明确核实的 stable-tourney 左右房间绑定、IPC 3、无当前异常 | 显示 Playing、当前房间谱面、实时队分与已有聊天；不依赖图池、Roll、BP或本局记录 |
| BP 操作 | 当前明确选择的队伍／动作、可用图池条目 | 可直接选择当前 Pick；早先 Ban/Pick 保持未知，不推定完整轮次 |
| 自动记胜 | 已有本局、正确谱面与run、连续观察到有效开打和结算、现有最终队分核验 | 不从首次 Playing／Ranking 快照补造开打或结果；保留人工记胜与系列比分修正 |

资料不足只能影响对应功能。缺少BP不影响实时画面，缺少最终成绩不阻止下一图；错误房间、断线或明确异常仍保留原核验边界。默认自动化意图保持开启，既有明确关闭设置不被恢复动作偷偷打开。

## 图池与当前局

主界面只使用一组队伍 Ban/Pick 按钮，先选动作或先选谱面均可。新图按明确选择处理；在准备期改图保留同一次Pick。正在Playing、已经打过、暂停或系列已结束时，允许修正播出标记，但不新增Ban/Pick、不改真实run、不覆盖赛果或系列分。

从第一步跟踪时，原OCLR顺序与先Ban／先Pick独立选择继续工作。直播员明确跳到当前Pick时不要求补齐过去Ban；若无法判断处于哪段OCLR轮换，清除未知的生成游标，等待明确的后续动作，不用旧队列强迫倒回比赛开头。明确提供的后续手动顺序仍保留。该行为仅处理BP定位，不增加全局人工接管模式。

TB仍由人工明确选择后单独准备，不混入普通Pick，禁Ban与EX。系列结束停止真实推进，Winner仍人工展示。撤销、空Ban、重赛、异常恢复、人工改胜方与撤回计胜继续保留。

## 中途初始化

初始化对话框显示已核实的房间左右名称，并提供“保留当前房间连接与自动跟随设置”。当前已接收到有效Playing数据时默认勾选；直播员可取消。不从播出队名或未知读数推断房间绑定。

- 保留连接：先存档，清空比赛资料／历史进度／比分并建立新会话；下一帧有效Playing接回实时显示，不创建run、不补计胜。保留原有自动化开关选择。
- 不保留：沿用原完整初始化，房间绑定与本场资料一并清空，再明确设置。
- 两种方式都可撤销。单纯自动接入Playing展示不增加额外撤销项，初始化后仍能一次撤销回到上一场。
